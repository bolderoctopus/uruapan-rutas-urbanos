# Security policy / Política de seguridad

## Supported versions / Versiones con soporte

Only the latest version on Google Play gets security fixes.

Solo la versión más reciente en Google Play recibe correcciones de seguridad.

## Reporting a vulnerability / Reportar una vulnerabilidad

Please don't open a public issue. Report it privately from the repository's **Security** tab with **Report a vulnerability**. You'll get an answer within 14 days. This is a personal project, so there is no bug bounty.

Por favor no abras un issue público. Repórtala en privado desde la pestaña **Security** del repositorio, con **Report a vulnerability**. Recibirás respuesta en un plazo de 14 días. Es un proyecto personal, así que no hay recompensas.

Useful details / Datos útiles:
- App version and Android version / Versión de la app y de Android
- Steps to reproduce / Pasos para reproducirla
- What an attacker could do / Qué podría hacer un atacante
